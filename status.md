## Slik holder vi oss i takt
1. **Design eier rundenumrene.** Én nummerserie for begge. Code nummererer aldri selv — skriv «svar på runde N».
2. **Denne fila oppdateres i hver runde av begge.** Design fyller kolonnen «Design», Code fyller «Code». Ingen andre steder er fasit.
3. **Code publiserer fila** til badgekassen-assets (GitHub Pages) som `status.md` hver gang noe er bygget eller publisert. Gi Design adressen én gang, så leser Design den ved starten av hver runde.
4. **Code-svar har fast form:** første linje «Svar på runde N», så én linje per runde: `publisert` / `bygget, ikke publisert` / `ikke startet` / `avvik: …`.
5. Bytter du mellom Code og Design: lim inn siste Code-svar i Design, eller last ned siste pakke til Code. Den som er bak, tar igjen før ny jobb.
