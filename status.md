## Slik holder vi oss i takt
1. **Design eier rundenumrene.** Én nummerserie for begge. Code nummererer aldri selv — skriv «svar på runde N».
2. **Denne fila oppdateres i hver runde av begge.** Design fyller kolonnen «Design», Code fyller «Code». Ingen andre steder er fasit.
3. **Code publiserer fila** til badgekassen-assets (GitHub Pages) som `status.md` hver gang noe er bygget eller publisert.
4. **Code-svar har fast form:** første linje «Svar på runde N», så én linje per runde: `publisert` / `bygget, ikke publisert` / `ikke startet` / `avvik: …`.
5. Bytter du mellom Code og Design: lim inn siste Code-svar i Design, eller last ned siste pakke til Code. Den som er bak, tar igjen før ny jobb.

## Svar fra Code på runde 50–54
- **Sjansen (spørsmål i runde 51):** tallene bygger på hver type for seg. Hvert craft gir én bakgrunn OG én emoticon, så Beeftacular har 1 av 7 (14,3 %) per bakgrunn og 1 av 8 (12,5 %) per emoticon. 1 av 15 er feil. Det stemmer med det dere rettet i runde 52.
- **Vekter etter sjeldenhet (spørsmål i runde 52):** sjeldenheten per gjenstand ligger i pool-filene (`rarity`: Common/Uncommon/Rare; 32 gjenstander mangler den). Ekte vekter kan vi ikke måle: det krever resultater fra mange craft, og Valve publiserer dem ikke. Behold «Lik sjanse» som standard, og merk «Vektet etter sjeldenhet» som et estimat.
- **Data per spill (runde 50):** alt ligger i https://impxmk.github.io/badgekassen-assets/data/pool/<appid>.json (Beeftacular: https://impxmk.github.io/badgekassen-assets/data/pool/491620.json; alle appid-er i https://impxmk.github.io/badgekassen-assets/data/pool/_index.json):
  - `badges`: { "1"…"5": full bildeadresse } for vanlig badge. **Mangler:** navnene på nivåene (Scared, Stressed …) og foil-badgen. Vi kan hente begge fra SteamCardExchange i datajobben.
  - `cards_art`: [{ name, icon, foil }]. Full adresse = https://community.fastly.steamstatic.com/economy/image/<icon>.
  - `items`: [{ name, type ("Bakgrunn"/"Emoticon"), rarity, icon_url, buy_usd, in_pool }]. buy_usd er høyeste ekte kjøpsordre i USD (før 15 % gebyr); kursen står i https://impxmk.github.io/badgekassen-assets/data/home.json under meta.usdNok. Bare gjenstander med in_pool ≠ false er i poolen. `pool_bg` og `pool_emote` er antallet per type.
- **Ny regel om bildekopier:** notert. Pertinence, MIND og Natsu bygges om så selve bildet flyttes.
- **Lyn som tiebreaker (v9):** notert. Bygges i neste tema-runde: under 25 % i bildets topp gir Sci-fi, Space, Futuristic og Robots lyn · plasma, Mech og Superhero lyn · bue.
