# badgekassen-assets

Statiske filer og data for https://steam-badges.vercel.app, servert av GitHub Pages.
Repoet skrives av nattjobbene (scripts/publish-assets.js i steam-badges) og holdes på én commit. Ikke rediger her.

- `data/` – home.json, craft.json, list.json, craft-index.json, pool/<appid>.json, badges.xlsx, meta.json
- `og/` – delingsbilder per spill (<appid>.jpg, 1200 × 630) og manifestet _index.json
- `emoticons/` – oppskalerte emoticons (216 × 216 WebP)
- `life/` – bildeliv: lagrigger, håndmalte lag og heltebilder (hero.json)
